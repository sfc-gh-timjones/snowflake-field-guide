Cost Implications

Understanding billing differences between Snowflake-managed and externally managed Iceberg tables

Storage Costs

  • ✔ Snowflake does NOT bill for storage
  • ✔ Cloud provider bills directly
  • ⚠ Cross-region = egress costs

Compute Costs

  • ✔ Standard warehouse credits
  • ✔ Same for both table types
  • ✔ Billed on warehouse usage

Additional Costs

  • Horizon API: 0.5 credit/M calls
  • Private connectivity charges
  • CLD: Cloud services compute

Optimization & Maintenance Costs

⚙ Snowflake-Managed

Higher operational convenience
Automatic maintenance with optimization billing. Best for teams wanting managed infrastructure.

Track costs: ICEBERG_STORAGE_OPTIMIZATION_HISTORY

🔗 Externally Managed

Lower Snowflake costs, more control
No automatic optimization billing. Best if you have existing catalog infrastructure.
